### Selected work

- **[sql-steward](https://github.com/Pawansingh3889/sql-steward)** — the agent never writes SQL. Queries compile from a semantic layer; blocked PII is refused before the query runs.
- **[governed-agent-stack](https://github.com/Pawansingh3889/governed-agent-stack)** — the on-prem stack around it: map the schema, query it, audit every step.
- **[steward](https://github.com/Pawansingh3889/steward)** — delegated spending, for when the person spending and the person paying are not the same person.
- **[pay-warden](https://github.com/Pawansingh3889/pay-warden)** — an MCP server that policy-checks a purchase before it reaches the payment rail.
- **[payoptimize](https://github.com/Pawansingh3889/payoptimize)** — routes each payment to the provider most likely to authorise it. Thompson sampling, decline-aware cascade.
- **[sql-sop](https://github.com/Pawansingh3889/sql-sop)** — rule-based SQL linter on PyPI. 48 rules, SARIF output, pre-commit hook.
